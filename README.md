# Deep Learning PYQ Visualizer: Backpropagation (Q53-56)

An interactive visualizer and step-by-step calculator for Deep Learning backpropagation exam problems.

## 🚀 Live Demo
Visit the live interactive page:
**[https://chinmoy1990.github.io/dl-backprop-visualizer/](https://chinmoy1990.github.io/dl-backprop-visualizer/)**

## ✨ Features
- **Network Graph & Flow Animation**: Live forward pass and backward backpropagation animated pulse flows.
- **Formula Inspector**: Real-time breakdown of weight updates, delta values, and gradients.
- **Step-by-step Execution**: Step forward and backward through forward computation and backward error propagation.
- **Customizable Weights & Inputs**: Test scenarios dynamically.

## 🛠 Tech Stack
- HTML5, CSS3 (Tailwind CSS)
- Vanilla JavaScript & SVG Visualizations
- GitHub Pages Deployment
