02Notation: sabse pehle yeh pakka karo

Lecture 4 (Module 4.1) ka convention. Exam ke questions bhi isi ko follow karte hain.

SymbolMatlab
h₀ = xInput ko layer 0 ka output maano. Input layer = 0th layer, output layer = L-th layer.
akPre-activation of layer k: weighted sum, activation lagne se pehle. ak = bk + Wkhk−1
hkActivation (output) of layer k = g(ak). g = sigmoid / tanh / ReLU …
ŷ = hL = O(aL)Output layer pe alag function O: classification ke liye softmax, regression ke liye linear.
Wk ∈ ℝm×pLayer k−1 (p neurons) → layer k (m neurons). Rows = current layer, columns = previous layer.
wkijLayer k ka weight, layer k ke neuron i (TO) tak, layer k−1 ke neuron j (FROM) se.
aki, hkiLayer k ke i-th neuron ka pre-activation / activation.
Index rule

wk i j = layer · TO · FROM. Yaad rakhne ka tareeka: ak = Wkhk−1 mein row i ka dot product hk−1 ke saath karte hain toh aki milta hai. Toh row = TO, column = FROM.

Example: w₂₃₁ = layer 2, output neuron 3 tak, hidden neuron 1 se.

03Big idea: blame peeche bhejna

Slides ka "responsibility" wala story (Module 4.4):

  1. Output pe loss −log ŷℓ aaya. Hum output layer se poochte hain: "tum galat kyun ho?"
  2. Output layer bolti hai: "main utni hi achhi hoon jitne mere neeche ke WL, bL aur hL−1."
  3. WL, bL poori zimmedaari lete hain. hL−1 bolta hai: "main utna hi achha hoon jitna mera pre-activation aL−1."
  4. aL−1 bolta hai: "main utna hi achha hoon jitne mere neeche ke weights aur hidden layer." Aise hi sabse neeche tak chalte jaate hain.

Kisi bhi weight se seedha baat karna mushkil hai. Isliye hum layers ke through baat karte hain, aur yahi chain rule hai:

∂L/∂W111 = ∂L/∂ŷ · ∂ŷ/∂a₃ · ∂a₃/∂h₂ · ∂h₂/∂a₂ · ∂a₂/∂h₁ · ∂h₁/∂a₁ · ∂a₁/∂W111 └ output layer ┘ └ prev hidden ┘ └ prev hidden ┘ └ weight

04Back jaane ka 4-line loop

Module 4.8 ka pseudo-code. Poora backprop bas itna hai:

// pehle forward pass: saare a₁,h₁,…,a_L, ŷ store karo ∇aL L = −(e(y) − ŷ) = ŷ − y for k = L down to 1: ∇Wk L = ∇ak L · hk−1ᵀ // weights of this layer ∇bk L = ∇ak L // bias of this layer ∇hk−1 L = Wkᵀ · ∇ak L // go down one layer ∇ak−1 L = ∇hk−1 L ⊙ g′(ak−1) // cross the activation
Exam strategy

Question chahe kisi bhi weight ka gradient maange, yahi order follow karo:

  1. Forward pass karo aur saare a, h, ŷ likh lo. Inki zaroorat peeche aate waqt padegi.
  2. Output pe ∂L/∂aL nikaalo (mostly ŷ − y).
  3. Jis layer ka weight chahiye, wahan tak Wᵀ aur g′ se neeche aao.
  4. Wahan ∂L/∂a (TO) × h (FROM) karo. Answer mil gaya.

05Step 1: output gradient ∂L/∂aL

Softmax + Cross-entropy (lecture ka main case)

Loss: L = −Σc yc log ŷc = −log ŷℓ, jahan ℓ = true class. y one-hot hai, toh sirf true class wala term bachta hai.

Derivation (Module 4.5) ka short version:

∂L/∂ŷi = −1(i=ℓ) / ŷℓ (sirf true class ka non-zero) ∂ŷℓ/∂aLi = ŷℓ(1(i=ℓ) − ŷi) (softmax ka quotient rule) ∂L/∂aLi = −1/ŷℓ · ŷℓ(1(i=ℓ) − ŷi) = −(1(i=ℓ) − ŷi) = ŷi − yi vector form: ∇aL L = −(e(ℓ) − ŷ) = ŷ − y

Matlab true class pe gradient ŷ − 1 (negative: "isko upar badhao") aata hai. Baaki classes pe ŷ − 0 (positive: "isko neeche girao").

Output / loss combinations: yeh table ratt lo

ProblemOutput OLoss∂L/∂aL
Multi-classsoftmaxCross-entropyŷ − y
BinarysigmoidBinary CEŷ − y
Regressionlinear½(ŷ − y)²ŷ − y
(Week 2 toy)sigmoid½(ŷ − y)²(ŷ − y)·ŷ(1 − ŷ)
Trap

Pehle teen cases mein answer ŷ − y aata hai, isliye log chauthe case mein bhi wahi likh dete hain. Sigmoid output + squared error mein extra ŷ(1−ŷ) factor lagta hai, kyunki sigmoid ka derivative cancel nahi hota. Aur linear output mein ŷ(1−ŷ) mat lagao, kyunki wahan ∂ŷ/∂a = 1 hai.

06Step 2: hidden layer tak jaana (∂L/∂h)

Ek hidden neuron hk−1,j agli layer ke har neuron ko feed karta hai. Toh loss tak pahunchne ke multiple paths hain, aur multi-path chain rule kehta hai ki saare paths ko add karo:

∂L/∂hk−1,j = Σm ∂L/∂ak,m · ∂ak,m/∂hk−1,j = Σm wk,m,j · ∂L/∂ak,m vector form: ∇hk−1 L = Wkᵀ · ∇ak L (W ka j-th column · upar wala gradient)
Intuition

Har output neuron apna error (ŷm − ym) wapas bhejta hai, aur woh error usi weight se scale hota hai jisse forward mein signal gaya tha. Hidden neuron saare incoming errors ko add kar leta hai. Σ mat bhoolna: Q56 jaise questions mein yahi sabse common galti hai.

07Step 3: activation ke through (∂L/∂a)

h = g(a) ⇒ ∂L/∂ak−1,j = ∂L/∂hk−1,j · g′(ak−1,j) (element-wise ⊙)
Activationg(z)g′(z)Shortcut (h = g(z))
Sigmoid1/(1+e−z)σ(z)(1−σ(z))h(1−h)
tanh(ez−e−z)/(ez+e−z)1 − tanh²(z)1 − h²
ReLUmax(0, z)1 if z>0, else 0a ≤ 0 ho toh gradient wahin ruk jaata hai
Linearz1kuch multiply nahi karna

Sigmoid derivative ki proof (Module 4.9): g′(z) = e−z/(1+e−z)² = [1/(1+e−z)]·[(1+e−z−1)/(1+e−z)] = g(z)(1−g(z)). Sigmoid ka derivative max 0.25 hota hai (z = 0 pe), isliye har sigmoid layer cross karte waqt gradient chhota hota jaata hai.

08Step 4: weights aur biases ka gradient

aki = bki + Σj wkij hk−1,j ∂L/∂wkij = ∂L/∂aki · ∂aki/∂wkij = ∂L/∂aki · hk−1,j ∂L/∂bki = ∂L/∂aki (kyunki ∂a/∂b = 1) matrix form: ∇Wk L = ∇ak L · hk−1ᵀ (outer product: column × row)

3×3 ka example. Har entry = (row ka ∂L/∂a) × (column ka h):

⎡ ∂L/∂ak1·hk−1,1 ∂L/∂ak1·hk−1,2 ∂L/∂ak1·hk−1,3 ⎤ ∇Wk L = ⎢ ∂L/∂ak2·hk−1,1 ∂L/∂ak2·hk−1,2 ∂L/∂ak2·hk−1,3 ⎥ ⎣ ∂L/∂ak3·hk−1,1 ∂L/∂ak3·hk−1,2 ∂L/∂ak3·hk−1,3 ⎦
One-liner

Weight ka gradient = jahan jaa raha hai (TO) uska ∂L/∂a × jahan se aa raha hai (FROM) uska output h. Isliye index padh ke formula seedha likh sakte ho.

Peeche se kyun? Har layer ka ∇a sirf ek baar compute hota hai aur us layer ke saare weights ke liye reuse ho jaata hai. Agar har weight ke liye alag se poora chain rule likhoge toh same cheez baar-baar compute hogi.

09Gradient descent update

θt+1 = θt − η ∇θt θ = [W₁ … WL, b₁ … bL] Week 2, single sigmoid neuron, L = ½(f(x) − y)²: ∇w = (f(x) − y) · f(x)(1 − f(x)) · x ∇b = (f(x) − y) · f(x)(1 − f(x))

Gradient positive ho toh weight ghatao, negative ho toh badhao (hamesha gradient ke ulte direction mein). Har iteration mein pehle forward, phir backward, phir update. Batch ho toh saare examples ke gradients ka sum (ya average) lo.

11Solved PYQs: 5 patterns jo baar-baar aate hain

Pattern A · Quiz-1 Sept 25 (Q53–56): softmax + CE, ek hidden sigmoid neuron

Given: x = h₀ = 2, W₁ = 1, W₂ = [w₂₁₁, w₂₂₁, w₂₃₁]ᵀ = [−1, 1, 2]ᵀ, y = [0, 1, 0], no bias, hidden = sigmoid, output = softmax.

Notes se bhara gaya

Question ∂L/∂a = ŷ − y aur σ′ = h(1−h) nahi deta. Dono Section 05 aur 07 se lo.

── Forward ── a₁ = W₁x = 2 h₁ = σ(2) = 0.88 ← Q53 (0.84–0.92) a₂ = W₂h₁ = [−0.88, 0.88, 1.76] ŷ = softmax(a₂) = [0.048, 0.279, 0.673] L = −ln ŷ₂ = −ln 0.279 = 1.28 ← Q54 (1.22–1.32) ── Backward ── ∂L/∂a₂ = ŷ − y = [0.048, −0.721, 0.673] Q55: ∂L/∂w₂₃₁ = ∂L/∂a₂₃ · h₁ = 0.673 × 0.88 = 0.59 (0.54–0.64) Q56: ∂L/∂W₁ = ∂L/∂h₁ · σ′(a₁) · x ∂L/∂h₁ = Σⱼ w₂ⱼ₁ (ŷⱼ − yⱼ) ← 3 paths ka SUM = (−1)(0.048) + (1)(−0.721) + (2)(0.673) = 0.577 σ′(a₁) = h₁(1 − h₁) = 0.88 × 0.12 = 0.1056 ∂L/∂W₁ = 0.577 × 0.1056 × 2 = 0.12 (0.06–0.18)

Pattern B · Quiz-1 Jan 26 (Q12–13): binary, sigmoid output, biases ke saath

Given: x = 1, y = 1. Hidden: w₁ = 1, b₁₁ = 0, w₂ = −1, b₁₂ = 0. Output: v₁ = 1, v₂ = 1, b₂₁ = 1. Dono layers sigmoid, loss = cross-entropy.

Notes se bhara gaya

Binary + sigmoid output + "cross entropy" ka matlab hai binary CE, toh ∂L/∂aout = ŷ − y. Question yeh nahi batata.

── Forward ── a₁₁ = w₁x + b₁₁ = 1 h₁ = σ(1) = 0.731 a₁₂ = w₂x + b₁₂ = −1 h₂ = σ(−1) = 0.269 a₂ = v₁h₁ + v₂h₂ + b₂₁ = 0.731 + 0.269 + 1 = 2.0 ŷ = σ(2) = 0.88 ← Q12 (0.86–0.90) ── Backward (w₁ = x → h₁) ── ∂L/∂a₂ = ŷ − y = 0.881 − 1 = −0.119 ∂L/∂h₁ = v₁ · ∂L/∂a₂ = −0.119 (h₁ sirf ek output ko feed karta hai) ∂L/∂a₁₁ = −0.119 × h₁(1−h₁) = −0.119 × 0.197 = −0.0234 ∂L/∂w₁ = ∂L/∂a₁₁ · x = −0.02 ← Q13 (−0.04–0.00)

Pattern C · Quiz-1 May 25 (Q46–47): regression, linear output

Given: x = −ln 3, y = 1 + 1/ln 3. w₁ = w₂ = 1 (input → do sigmoid neurons), w₃ = 8, w₄ = −4 (→ linear output). L = ½(ŷ − y)², no bias.

── Forward ── a₁ = a₂ = 1·(−ln 3) = −ln 3 h₁ = h₂ = 1/(1 + eln 3) = 1/(1+3) = 0.25 ŷ = w₃h₁ + w₄h₂ = 8(0.25) − 4(0.25) = 1 ← Q46 ── Backward ── ∂L/∂ŷ = ŷ − y = −1/ln 3 (linear output ⇒ ∂ŷ/∂a = 1, koi ŷ(1−ŷ) nahi) ∂L/∂w₁ = (ŷ − y) · w₃ · h₁(1−h₁) · x = (−1/ln 3) · 8 · (0.25 × 0.75) · (−ln 3) = 8 × 0.1875 = 1.5 ← Q47
Annotated PDF mein confusion

Page 12 pe (ŷ−y)·ŷ(1−ŷ)·x₁ likha hai. Woh formula sigmoid output wale single neuron ka hai, yahan apply nahi hota. Sahi path page 11 wala hai: ŷ → h₁ (w₃) → a₁ (σ′) → w₁ (x). Answer 1.5 usi se aata hai.

Pattern D · Quiz-1 Sept 24: single sigmoid neuron, ek GD step, phir naya loss

Given: x = [1, 0.5, 1], w = [0.5, 1, 0.5], b = 1, y = 0, L = ½(y − ŷ)², η = 2.

z = wᵀx + b = 0.5 + 0.5 + 0.5 + 1 = 2.5 ŷ = σ(2.5) = 0.924 L = 0.427 δ = (ŷ − y)·ŷ(1 − ŷ) = 0.924 × 0.924 × 0.076 = 0.065 (sigmoid + SE ⇒ extra ŷ(1−ŷ)) ∇w = δ·x = [0.065, 0.032, 0.065] ∇b = δ = 0.065 wnew = w − 2∇w = [0.37, 0.935, 0.37] bnew = 1 − 2(0.065) = 0.87 znew = 0.37 + 0.4675 + 0.37 + 0.87 = 2.08 ŷnew = σ(2.08) = 0.889 Lnew = ½(0.889)² = 0.395 (0.37–0.41)

Loss 0.427 se 0.395 pe aa gaya, matlab update sahi direction mein hua.

Pattern E · Quiz-2 2025 (Q243–244): deep thin ReLU chain

Given: x = 1, y = 0. n−1 hidden layers mein ek-ek ReLU neuron, output linear, L = ½(ŷ − y)², no bias, saare wi = k > 0.

Forward: har layer k se multiply karti hai (ReLU positive values ko waise hi pass karta hai) ŷ = k·k·…·k·x = kⁿ ← Q243 Backward: ∂L/∂w₁ = (ŷ − y) · [wn · wn−1 ⋯ w₂] · x (ReLU′ = 1, sab positive hai) = kⁿ · kⁿ⁻¹ · 1 = k²ⁿ⁻¹ ← Q244

Yeh lecture ka "deep but thin network" case hai: ek hi path, toh chain rule mein seedha multiply karte jao.

Bonus · Zero-initialisation wale MCQs (Sept 25 Q61–62)

Setup: hidden layer sigmoid, output softmax, W₁ random, W₂ = 0, bias = 0. Ek GD step ke baad:

∇h1 L = W₂ᵀ · ∇a2 L = 0ᵀ · (…) = 0 ⇒ ∇W1 = 0 ⇒ W₁ same rehta hai (Yes) ∇W2 L = ∇a2 L · h₁ᵀ = (ŷ − y)·h₁ᵀ ≠ 0 ⇒ W₂ badalta hai (No)

Rule: kisi layer ke weights zero hon toh us layer se neeche gradient nahi jaata (Wᵀ se multiply hota hai), lekin us layer ke apne weights phir bhi update hote hain (kyunki unka gradient ∇a · hᵀ hai).

12Common traps: exam se pehle ek baar padh lena

  1. Σ bhool jaana: hidden neuron agar kai outputs ko feed karta hai toh ∂L/∂h = Σm wm(ŷm − ym), sirf true class ka term nahi.
  2. Galat output derivative: ŷ(1−ŷ) sirf sigmoid output + squared error mein lagta hai. Softmax+CE, sigmoid+BCE aur linear+SE teeno mein seedha ŷ − y.
  3. Index ulta padhna: wkij = TO i, FROM j. ∂L/∂wkij = ∂L/∂aki × hk−1,j.
  4. h aur a mix karna: σ′ ko a pe evaluate karte hain, lekin shortcut h(1−h) mein h use hota hai. σ′(a₁) = h₁(1−h₁), na ki a₁(1−a₁).
  5. Weight gradient mein galat h: FROM layer ka output hk−1 lo, pre-activation nahi. Pehli layer ke liye yeh x hai.
  6. ReLU dead path: a ≤ 0 ho toh gradient 0 ho jaata hai, aur us path se neeche kuch nahi jaata.
  7. Rounding: beech ke steps 2 decimal tak round karo jaise question kehta hai. Exact answer bhi range ke andar hi aayega.
  8. GD ka sign: w − η∇w hota hai, + nahi.
